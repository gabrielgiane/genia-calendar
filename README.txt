GENIA CALENDAR - prima versione di prova

Per pubblicare su GitHub Pages:
1. Apri il repository genia-calendar.
2. Add file > Upload files.
3. Carica index.html nella cartella principale del repository.
4. Premi Commit changes.
5. In Settings > Pages scegli Deploy from a branch, branch main e folder /(root), poi Save.

Questa versione salva calendari e appuntamenti nel browser del dispositivo (localStorage).
Non sincronizza ancora i dati tra dispositivi: per quello servirà collegare un database online.
